# SISTEMA BANCÁRIO 3.0

## Este projeto é o terceiro de uma série de projetos propostos pela escola Digital Inovation One (DIO) do curso de formação em Python

### Este projeto conta com diversas funcionalidades básicas de um sistema bancário tradicional, além de contar com vários verificadores de segurança para evitar possíveis entradas de dados incompatíveis e manter sempre um padrão.

### Nesta nova versão, o sistema conta com um extrato para cada conta seja corrente ou poupança, mostrando todas as movimentações de saques, depósitos e transferências.
